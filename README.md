About the project

I built this website to keep track of my personal LEGO Star Wars collection. I wanted to practice my web development skills on a real project rather than just doing academic tutorials, so I decided to combine my hobby with programming.

It's a simple CRUD (Create, Read, Update, Delete) application built from scratch without any heavy frameworks.

Built With

Frontend: HTML, CSS, JavaScript (Vanilla)

Backend: PHP (Vanilla)

Database: SQL (hosted on Alwaysdata)

Features

View the complete collection of my LEGO sets.

Add new sets to the database.

Update or delete existing entries.

Simple and responsive user interface.

Why I made this

I mentioned this project in my resume because it really helped me understand how the front-end connects to a back-end and a database. Writing the SQL queries myself and managing the hosting on Alwaysdata was a great learning experience.
